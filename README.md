# Pets

Codex custom pet assets.

## Xiuxiu

`pets/xiuxiu` contains the installable Xiuxiu pet package:

- `pet.json`
- `spritesheet.webp`

Preview contact sheet:

- `previews/xiuxiu-contact-sheet.png`

Xiuxiu is a playful, warm, patient little-girl pixiu pet. The package preserves the approved feather wings, small dragon horns, pink/lavender/white palette, jewelry, starry eyes, curled tail, and cute pixiu identity.
